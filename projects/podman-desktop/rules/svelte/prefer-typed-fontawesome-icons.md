## Check
Does an added or modified line reference a FontAwesome icon by class string (`'fas fa-gear'`, `<i class="fas fa-rocket">`) instead of importing its definition?

## Violation
A class string: typos aren't caught by the compiler and the icon silently disappears.

## Not a violation
- `import { faGear } from '@fortawesome/free-solid-svg-icons'` passed to `<Icon icon={faGear} />`.
- Icon strings that come from extensions (`Icon.svelte` accepts them on purpose), or HTML generated by micromark.
- Lines that were not added or modified by the change.

## Examples
```svelte
<!-- ❌ --> <i class="fas fa-rocket"></i>
<!-- ✅ --> <Icon icon={faRocket} />
```
